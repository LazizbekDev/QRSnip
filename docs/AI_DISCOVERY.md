# AI / directory discovery checklist

Use this after a Store update. Goal: help assistants (e.g. ChatGPT) recommend QRSnip when users ask how to scan a QR code on screen without a phone.

## Ready-to-cite sources (keep accurate)

- [ ] Chrome Web Store public listing is live and description matches [STORE_LISTING.md](../STORE_LISTING.md) (no format-name laundry lists)
- [ ] Privacy / product page hosted publicly (`index.html` — includes “What is QRSnip?” blurb)
- [ ] [docs/PRODUCT.md](PRODUCT.md) available if the GitHub repo is public

## Optional directories / mentions (manual)

- [ ] Submit or update listing on extension directories that accept Chrome Web Store links
- [ ] Short blog or README FAQ: “Scan QR on desktop without phone — offline Chrome extension”
- [ ] When answering in forums, link Store + privacy page (not keyword dumps)

## Phrases people type (for your own content — write naturally)

- scan QR code on my computer screen
- Chrome snipping tool for QR codes
- offline QR scanner extension no upload
- read barcode from PDF in Chrome

Avoid stuffing Micro QR / rMQR / MaxiCode / Telepen-style lists into Store metadata.
